# Безопасность публичного репозитория

- Не добавляйте сюда токены, пароли, `.env`, закрытые ключи, сертификаты подписи приложений,
  профили provisioning или `export_credentials.cfg`.
- Сборки GitHub Actions используют только автоматически выдаваемый репозиторию `GITHUB_TOKEN`.
  В файлах проекта токен не хранится.
- Перед публикацией проверяйте весь индекс Git сканером секретов, а не только видимые файлы.
- Если вы нашли опубликованный секрет, не вставляйте его в публичный Issue. Сразу отзовите секрет
  у его провайдера и свяжитесь с владельцем репозитория через профиль GitHub.
