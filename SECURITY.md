# Security

Не публикуйте найденные ключи, токены или персональные данные в обычном Issue.

Используйте [Private vulnerability reporting](https://github.com/Prokopiy8247/Claude-Opus-5.5-Minecraft/security/advisories/new). Если обнаружен действующий секрет, сначала отзовите или замените его у соответствующего провайдера, затем отправьте приватный отчёт с путём файла и коммитом.

Проверить текущий снимок репозитория локально можно командой:

```bash
python "Unity Opus 5.5 Minecraft/Tools/check_secrets.py"
```
