# Godot Opus 5.5 Minecraft

Одиночная песочница от первого лица, созданная на Godot 4.7.2 в рамках эксперимента с
Claude Opus 5.5. Для запуска готовой игры устанавливать Godot, Blender или другие инструменты
не нужно.

Исходный промпт сохранён без изменений в файле [`Godot_Minecraft_Prompt`](./Godot_Minecraft_Prompt).

## Самый простой запуск

Перейдите на страницу
[последнего релиза](https://github.com/Prokopiy8247/Claude-Opus-5.5-Minecraft/releases/latest)
и скачайте архив для своей системы.

### Windows 10/11

1. Скачайте `GodotMinecraft-Windows-x86_64.zip`.
2. Нажмите на архив правой кнопкой и выберите **Извлечь всё**. Не запускайте игру прямо из
   архива.
3. В распакованной папке дважды щёлкните `GodotMinecraft.exe`.
4. Если SmartScreen предупредит о неизвестном издателе, убедитесь, что архив скачан именно из
   этого репозитория, затем выберите **Подробнее → Выполнить в любом случае**. Сборка не имеет
   платного сертификата подписи.

### macOS

Сборка универсальна: она подходит для Mac с Intel и Apple Silicon.

1. Скачайте `GodotMinecraft-macOS-universal.zip` и распакуйте его двойным щелчком.
2. Перетащите `Godot Minecraft.app` в папку **Applications/Программы**.
3. При первом запуске нажмите на приложение с удержанием **Control**, выберите **Open/Открыть**,
   затем ещё раз **Open/Открыть**. Это требуется потому, что любительская сборка не
   нотарифицирована Apple.
4. Если macOS всё равно сообщает, что приложение нельзя открыть, выполните в Terminal:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Godot Minecraft.app"
   ```

   После этого снова откройте приложение. Используйте эту команду только для архива, который вы
   скачали со страницы релизов этого репозитория.

На первом запуске подготовка процедурных ресурсов может занять несколько секунд.

## Начать игру

В главном меню выберите **Singleplayer → Create New World → Create**. По умолчанию создаётся
творческий мир; режим и сложность можно поменять перед созданием.

## Основное управление

| Клавиша | Действие |
|---|---|
| `W A S D` | Движение |
| Мышь | Обзор |
| `Space` | Прыжок; двойное нажатие включает полёт в Creative |
| `Left Shift` | Красться / снижаться в полёте / слезть с транспорта |
| `Left Ctrl` | Бег |
| Левая кнопка мыши | Атака / разрушение блока |
| Правая кнопка мыши | Использовать / поставить блок / взаимодействовать |
| Колесо мыши, `1–9` | Выбор слота |
| `E` | Инвентарь |
| `Q` / `Ctrl+Q` | Выбросить предмет / стопку |
| `T` / `/` | Чат / командная строка |
| `Esc` | Пауза / закрыть окно |
| `F3` | Отладочная информация |
| `F4` | Сменить режим игры |
| `F5` | Сменить камеру |
| `F7` | Панель администратора |
| `F11` | Полноэкранный режим |

Полный список возможностей находится в [`FEATURE_MATRIX.md`](./FEATURE_MATRIX.md), а технические
заметки — в [`DEVELOPMENT.md`](./DEVELOPMENT.md).

## Запуск исходников в Godot

1. Установите [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/).
2. В Project Manager нажмите **Import** и выберите этот файл `project.godot`.
3. Откройте проект и нажмите **F5**, чтобы запустить всю игру.

Проект использует только GDScript. Blender нужен лишь для пересборки исходных 3D-моделей и для
обычного запуска не требуется.

## Сохранения

- Windows: `%APPDATA%\Godot\app_userdata\Godot Minecraft\saves\`
- macOS: `~/Library/Application Support/Godot/app_userdata/Godot Minecraft/saves/`

Игра однопользовательская, не требует аккаунта и не отправляет телеметрию. Сохранения остаются
на компьютере игрока.
