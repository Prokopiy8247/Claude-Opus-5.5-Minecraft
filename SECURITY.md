# Безопасность публичного репозитория

- Не добавляйте сюда токены, пароли, `.env`, закрытые ключи, сертификаты подписи приложений, профили provisioning, `export_credentials.cfg` или персональные пути.
- Сборки GitHub Actions используют только автоматически выдаваемый репозиторию `GITHUB_TOKEN`. В файлах проекта токен не хранится.
- Перед публикацией проверяйте весь индекс Git сканером секретов, а не только видимые файлы.
- Если обнаружен действующий секрет, сначала отзовите или замените его у соответствующего провайдера.
- Не публикуйте найденные секреты или персональные данные в обычном Issue. Отправьте приватный отчёт через [Private vulnerability reporting](https://github.com/Prokopiy8247/Claude-Opus-5.5-Minecraft/security/advisories/new), указав путь файла и коммит.

Проверка Unity-снимка локально:

```bash
python "Unity Opus 5.5 Minecraft/Tools/check_secrets.py"
```
