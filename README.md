# Claude Opus 5.5 Minecraft

Публичный репозиторий проектов, созданных Claude Opus 5.5 для сравнительного YouTube-видео: одна идея игры,
реализованная в разных движках. Каждый движок находится в отдельной папке и имеет собственный гайд по запуску.

## Проекты

- [Unreal Opus 5.5 Minecraft](Unreal%20Opus%205.5%20Minecraft/) — Unreal Engine 5.8, C++ и оригинальные ассеты.

В дальнейшем рядом могут появиться отдельные папки для Unity и Godot.

## Быстрый старт Unreal-версии

Откройте папку [Unreal Opus 5.5 Minecraft](Unreal%20Opus%205.5%20Minecraft/) и следуйте инструкции для своей системы:

- Windows: `Launch-Windows.bat`
- macOS: `Launch-macOS.command`

Для первого запуска потребуется Unreal Engine 5.8.x и системный C++ toolchain. Запускатели автоматически собирают
модуль и открывают проект; подробные шаги и решение частых проблем находятся в README проекта.

> Это независимый демонстрационный проект. Он не связан с Mojang Studios или Microsoft и не содержит их игровых
> ассетов, кода, звуков, шрифтов или логотипов.
